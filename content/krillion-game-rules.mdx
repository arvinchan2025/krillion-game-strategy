Krillion's live interface is the authority for current gameplay rules. The public FAQ provides useful information about answer curation and rarity, but it does not publish every internal detail.

## Answer-set curation

The creator says relevant datasets are aggregated, merged and cleaned. Examples include dictionaries, wiki pages and encyclopedias.

## Rarity

Some questions can be assessed using familiarity data. Other questions require LLM assistance and a manual review process. The method depends on the prompt.

## The Krillion selection

The top selection is not based on rarity alone. The creator also considers fun factor and whether the answer is satisfying for players.

## Aliases and autocorrect

The FAQ explains that some questions have many accepted answers and aliases. Autocorrect may match a close spelling to an alias, which can sometimes produce surprising matches.

## Missing answers

The creator acknowledges that a fair answer can be missing if a source was overlooked. This means the accepted set should not be assumed to be a perfect list of every valid response.

## Verify live rules

For the current instructions, visit [Krillion](https://krillion.io) and read its [official FAQ](https://krillion.io/faq). This guide intentionally avoids inventing unconfirmed details such as exact round counts, time limits or hidden score formulas.
